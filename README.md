# Renta Homebrew tap

Homebrew formulae for [Renta](https://renta.im) command-line tools.

## Install

```shell
brew install renta-im/tap/renta
```

Upgrade with `brew upgrade renta`, remove with `brew uninstall renta`.

The formula installs the `renta` binary, its man pages and command completion
for bash, zsh and fish.

## Without Homebrew

Every release on this repository carries a static binary for macOS, Linux
(amd64 and arm64) and Windows. Download the archive for your platform from
[Releases](https://github.com/renta-im/homebrew-tap/releases), verify it against
`checksums.txt` and put the binary on your `PATH`.

On macOS an archive downloaded through a browser is quarantined by Gatekeeper.
Clear it with `xattr -d com.apple.quarantine ./renta`, or install through
Homebrew, where this does not happen.

## What lives here

`Formula/renta.rb` is generated by GoReleaser on every release — do not edit it
by hand. The release assets it points at are attached to this repository.
